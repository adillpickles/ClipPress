Why ClipPress

Cut without the wait.

Built for the job most editors overcomplicate: pull the good minute out of a long recording and share it.

≫

Fast, lossless cutting

ClipPress is built on the LosslessCut engine and FFmpeg, so cuts avoid unnecessary re-encoding. You keep source quality and skip long render queues.

  • Keep-source-quality export path
  • Target-file-size export when you need small
  • Wide video + audio format support via FFmpeg
⌁

Precise trim, honest output

Mark segments on the timeline, review them, then export exactly what you marked — as separate clips, one merged clip, or both.

  • Multi-segment export modes
  • Project save / load for repeatable edits
  • Simple mode by default, Advanced when needed
✎

Light touches, built in

Small fixes without opening a full editor: lightweight text callouts and practical per-track volume fixes.

  • Text overlays for captions + callouts
  • Per-track audio gain
  • Keyboard-first: I / O, shortcuts throughout

Workflow

Open → mark → export.

The default path is deliberately short. Advanced controls stay out of the way until you ask for them.

1

Open a recording

Drop in a long capture. No project setup, no import dance.

2

Mark I / O

Set in/out points. Add more segments when one clip isn’t enough.

3

Tidy up

Optional text overlay or per-track gain fix. Stay in Simple mode or switch to Advanced.

4

Export + share

Keep source quality or hit a target size. Separate, merged, or both — ready for Discord or anywhere.

✓

Careful with your files

Recent preview work focused on the unglamorous stuff: safer output-path handling, a tightened local HTTP surface and CLI parsing, plus stability fixes for media-load races, empty-folder crashes, undo-history growth, and overlay bounds.

◍

Desktop-native, no account

No backend, no sign-in, no upload step. ClipPress runs locally with FFmpeg, stores settings, shortcuts, logs, and caches in the OS app-data folder, and uninstalls by deleting the app folder plus that data.

FAQ

Straight answers.

Is there a preview I can download yet?

Preview builds appear on the Releases page when published. If the button above says “coming soon”, the first preview hasn’t been tagged yet — use “Get notified” on GitHub or build from source.

Which platforms are supported?

The tested path is a Windows x64 portable EXE (built + smoke-tested in CI on tag). macOS and Linux artifacts are not published from this repo’s current pipeline. macOS would ship as a .dmg and Linux as an archive when enabled — check Releases for current state.

Does ClipPress re-encode my video?

Not unless you ask it to. The default keep-source-quality path cuts without unnecessary re-encoding (LosslessCut engine + FFmpeg). Use target-file-size export only when you explicitly want a smaller file.

What can I actually edit?

Only what the app really does: I/O segments, Simple vs Advanced modes, text overlays, per-track audio gain, keep-quality or target-size export, multi-segment export (separate / merged / both), keyboard shortcuts, and project save/load. No effects library, no timeline plugins — by design.

Is it free? What’s the license?

Yes — free, ad-free, open source under GPL-2.0-only. If it saves you time, the project accepts voluntary tips via the link in the repo README.

How is ClipPress related to LosslessCut?

ClipPress is built on top of LosslessCut by Mikael Finstad and its contributors. Same lossless-cutting foundation, refocused on the fast “long recording → shareable clip” workflow with Simple/Advanced modes, text, and gain.

Is there an installer? Where are my settings?

There is no installer. On Windows, extract the archive and run the executable; on macOS mount the .dmg and drag to Applications. Settings, shortcuts, logs, and caches live in the OS app-data folder (%APPDATA%\ClipPress on Windows). Delete that folder plus the app to fully uninstall.
