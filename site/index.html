Windows 10/11 x64 · v0.1.0 Beta 3 · unsigned preview build

  1. Trim

    Mark in and out with I and O. Add a text overlay, pull down a loud track, split the recording into as many segments as you need.

  2. Target

    Keep source quality copies the original streams where the format allows it. Or type a target size in megabytes and pick a quality preset.

  3. Export

    ClipPress plans the bitrate, chooses the encoder, and measures the finished file against your target. If it overshoots, it tries again.

Enough editing to finish the clip.

Simple mode keeps the everyday path clear. Advanced mode opens up the encoder, resolution and frame-rate controls for the clips that need them.

  • Text overlays for callouts and captions
  • Per-track audio gain when one source is too loud
  • Export segments separately, merged into one clip, or both
  • Quality, resolution and frame-rate presets for size-limited exports
  • Keyboard shortcuts, and projects you can save and reopen
