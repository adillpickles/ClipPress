Workflow

Cut in seconds. Not minutes.

Most desktop editors force you through timeline setup, transcode imports, and heavy rendering queues. ClipPress strips away the friction.

01

Drop and scrub

Drag any video file directly into ClipPress. Instant playback powered by FFmpeg — no project wizard, no proxy generation, zero import wait time.

MP4 MKV MOV WebM AVI
02

Mark with I and O

Scrub with your keyboard. Hit I to set your in-point, hit O to set your out-point. Need multiple segments from the same long recording? Tap + to mark additional clips.

True lossless stream copying

ClipPress slices video packets directly along keyframes without decoding and re-encoding video streams. Source bitrates and image quality remain 100% untouched.

FAQ

Frequently asked questions.

Where do I download ClipPress?

You can download ClipPress v0.1.0 Beta 3 directly via the Download button above for the portable ClipPress-Windows-x64.exe executable, or inspect all builds and release notes on the GitHub Releases page.

Does ClipPress re-encode my video?

Not during standard trims. The default "Keep Source Quality" path performs lossless stream cutting via FFmpeg, copying video and audio packets directly without re-encoding. You only re-encode if you explicitly enable the target-file-size export mode (e.g. hitting 25MB for Discord) or apply filters that require frame recalculation.

Which operating systems are supported?

Precompiled binary releases are packaged specifically for Windows 10/11 x64 as a standalone portable EXE. There are currently no prebuilt macOS or Linux binaries in the release pipeline; however, macOS and Linux users can easily clone the repository and run from source using Node 22 and FFmpeg.

How is ClipPress related to LosslessCut?

ClipPress is built directly on top of LosslessCut by Mikael Finstad. It preserves the battle-tested lossless cutting engine while tailoring the interface toward fast clipping workflows: streamlined Simple/Advanced views, multi-segment export presets, per-track audio volume gain, and text overlays.

Is there an installer? Where is my data saved?

There is no installer. ClipPress is distributed as a portable executable: simply download ClipPress-Windows-x64.exe, move it wherever you like, and run it. Your application settings, hotkeys, and temporary caches are stored locally in %APPDATA%\ClipPress. To cleanly uninstall, simply delete the EXE and that folder.

Is ClipPress free? What is the license?

Yes. ClipPress is 100% free, tracker-free, and published under the GPL-2.0-only license.
