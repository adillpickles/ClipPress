Windows 10/11 x64 · v0.1.0 Beta 3 · unsigned preview build

  1. Mark

    Press I for the start and O for the end. That is the whole loop for a single clip.

  2. Cut

    Export the selected segment. Mark several and get separate clips, one merged clip, or both.

  3. Skip the render

    Keep source quality copies the original streams rather than re-encoding them, so the export is a copy, not a render.

Enough editing to finish the clip.

Simple mode is the default and keeps the everyday path clear. Advanced mode is there when a clip needs more, and it is still experimental.

  • Target file size export, for uploads that have a cap
  • Text overlays for quick callouts and captions
  • Per-track audio gain when one source is too loud
  • Multi-segment export as separate clips, one merged clip, or both
  • Keyboard shortcuts and project save and load

Open source

Don't like something? Fork it.

The whole app is in the repository. Clone it, change what bothers you, and build your own. 

$ git clone https://github.com/adillpickles/ClipPress
$ yarn
$ yarn download-ffmpeg-win32-x64
$ yarn dev
