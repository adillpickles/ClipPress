Suggested export checks (the simple editor's names, with advanced mode's in brackets):
- **Original quality** (*Lossless export*) still cuts quickly and keeps the picture as it is.
- **Fit a file size** (*Limit file size*) makes an MP4 that stays under the size you set in normal cases.
- The **Max Quality**, **Quality** and **Fast** presets each finish for one clip, and for several clips with
  **One file per clip**, **One merged file** and **Both** (*Separate files*, *Merge cuts*, *Merge & Separate*).
